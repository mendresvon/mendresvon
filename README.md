## About

I'm a Filipino CS student at Southern Taiwan University of Science and Technology, currently working on transfer-learning research in multimodal emotion recognition alongside full-stack and applied-ML side projects. I care about building things that work end-to-end — from a trained model to a deployed API to a UI someone can actually click through.
