## About

I'm a Filipino CS student at Southern Taiwan University of Science and Technology. I work on transfer-learning research in multimodal emotion recognition and build full-stack and applied-ML projects. I like projects that work from model training through a deployed API and a usable interface.

## Featured Projects

| Project | What it is |
| :--- | :--- |
| [**multimodal-causal-ablation**](https://github.com/mendresvon/multimodal-causal-ablation) | Neuron-level causal validation of modality competition in multimodal emotion recognition. Contribution to a paper co-authored with faculty at NCKU, using linear probes and activation ablation on audio, text, and video models. |
